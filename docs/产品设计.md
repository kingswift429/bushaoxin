# 不烧心 · 产品设计文档

> Better name, better product. 本文档定义「不烧心」相对「钱包请等等」的全部优势。

---

## 命名

**不烧心**（副标题：花得值，不烧心）

「不烧心」是 2026 年 10 月由短剧台词「贵是贵了点，但吃了不烧心」带火的网络热梗，
已引申为「靠谱、省心、没有猫腻、不糊弄人、不踩雷」
（[新安晚报](https://epaper.ahwang.cn/xawb/20261016/html/content_20261016005001.htm)）。

选它的三个理由：
1. **语义完全重合** —— 用户要的就是"这钱花得安不安心"，审批的终点就是"不烧心"。
2. **名字即结论** —— 被驳回时可以说"这不烧心吗？"；通过时说"这钱花得踏实、不烧心"。
3. **梗有寿命，词没有** —— "不烧心"本身是通用词，热梗过去后产品名依然成立，
   不像纯玩梗命名会随梗一起过期。

备用名（若商标冲突）：**「这笔不烧心」**、**「审一下」**、**「冷静官」**。

## 一、原产品的优势（必须 100% 复刻）

| # | 优势 | 为什么是护城河 |
|---|---|---|
| 1 | **审批必须写理由** | 只投票会退化成玩梗；写理由才产出真实建议，形成口碑 |
| 2 | **先投票才解锁他人观点** | 反"前三楼定调"，拿到第一真实反应，这是最核心设计 |
| 3 | **驳回 = 即时省钱反馈** | 抽象自控 → 具体数字，制造传播点 |
| 4 | **极低填单门槛** | 商品名/价格/理由/替代，四格搞定 |
| 5 | **替代方案字段** | 逼用户自己先想省钱办法，是被低估的巧思 |
| 6 | **社交货币** | 可晒、可围观、可组群，Slogan 自带传播力 |
| 7 | **小额为主调性** | 中位数 50~120 元，日常化、不严肃 |

以上 7 条在实现里逐条落地，一条不丢。

## 二、我们更好的东西（差异化）

### ★ 核心杀器：截图识别自动填单（已实现）

用户看到想买的商品，截图 → 打开不烧心 → 点「从截图导入」→ 自动填好商品名和价格。

- 用 **VisionKit `DataScannerViewController`**（iOS 16+）实时识别，
  或 **Vision `VNRecognizeTextRequest`** 对相册图片离线识别。
- 识别后用启发式规则抽取：**带 ￥/¥/元的数字取最大者作价格**，
  **最长的非价格中文行作商品名**，行内含"券/包邮/月销"的剔除。
- 增强（需 API Key）：接 GPT-4o-mini / 豆包视觉模型兜底，把"猜"变成"懂"。

> 为什么小程序做不到：小程序调不起实时相机 OCR，只能走上传→服务端识别，
> 延迟 2~5 秒还烧服务器钱。**这是苹果开发者账户给的原生优势，直接变成产品壁垒。**

### ★ 延迟决策计时器（已实现）

原产品的"24 小时冷静期"只是页面上一句 Slogan，**没有真实机制**。
不烧心把它做成真的：提交后进入 24h 倒计时，到点本地通知问一句"现在还想买吗？"。

- 用户点"我还是想要" → 才算真正批准，进入购买；
- 用户点"算了" → 记一笔省下。
- 冷静期可调（2h / 12h / 24h / 3天）。

### ★ 真实省钱账本与年度报告（已实现）

把"为你省下 X 元"从卡片上的一句话，变成**长期资产**：

- 累计省下总金额（黑金卡片，产品的情感锚点）
- 连续克制天数（Streak，游戏化留存）
- 按分类的省下分布（餐饮/穿搭/数码…）
- 年度报告：这一年网友帮你省了多少、最常被驳回的是什么

### ○ 审批群与好友链（设计完成，本期先做本地群）

熟人审批比陌生人更黏、更可控，也规避了个人主体的社交类目风险。

### ○ 送花代替评论区

原产品因为"怕对骂"放弃了评论，只做送花。我们保留送花并加"神评上墙"：
被送花最多的理由置顶展示，用正向激励替代负向争吵。

## 三、为什么是 App 而不是小程序

| 维度 | 小程序 | 不烧心 App |
|---|---|---|
| 相机/相册 OCR | 需上传服务端，慢 | **原生实时，<300ms** |
| 本地通知 | 需订阅消息模板，用户易流失 | **原生定时通知，必达** |
| 屏幕使用时间/快捷指令 | 不可用 | **可做「购物 App 打开时弹审批」** |
| 数据存储 | 平台云 | 本地 SwiftData + Supabase 自控 |
| 品牌感 | 弱 | 强（App Store 首发即背书） |

## 四、合规要点（上架前必读）

1. UGC 必须做内容审核 → 提交前本地敏感词过滤 + 服务端二次校验；
2. 不得出现"理财/帮你管钱/借贷"表述，定位是**消费决策辅助工具**；
3. 隐私清单 `PrivacyInfo.xcprivacy` 必须声明相机、相册、通知用途；
4. 拒绝支付相关功能，本期完全免费无内购，规避 IAP 审核。
