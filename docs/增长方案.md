# 不烧心 · 冷启动增长方案

> 一个残酷的前提：2025 年全球上线约 **140 万个 App，只有约 10% 获得了真正的用户关注**
> （[AppMagic 2026 市场报告](https://appmagic.rocks/research/mobile-landscape-report-2026)，经 [Setapp 启动指南](https://setapp.com/how-to/launch-an-app) 引用）。
> 产品做得好是入场券，不是胜负手。**分发能力才是。**

---

## 一、先说结论：我们最大的增长杠杆是什么

不是买量，不是 ASO，是**产品本身自带传播场景**。

「钱包请等等」9 小时 1 万用户、次日 4 万，靠的不是推广费——是**用户自己截图分享**。

看这个场景：

```
用户发一笔「第九个手机壳 ¥39」
   ↓
网友驳回，理由写得特别扎心：
   "你有 8 个了。它们在哪？找出来我看看。"
   ↓
用户被戳中 → 把这张卡片截图发到小红书/朋友圈/群聊
   ↓
朋友看到："哈哈这什么 App" → 下载
```

**每一次成功的驳回，都是一次免费的传播。**
这不是我们设计出来的营销，是产品机制的副产品。

所以增长方案的第一原则：**把分享路径做到最顺滑，其他都是辅助。**

---

## 二、四条渠道，按投入产出排序

### 渠道 1：内容自传播（最重要，成本最低）

| 动作 | 说明 |
|---|---|
| **分享卡片优化** | 驳回后生成一张竖版图（1080×1440）：商品名 + 价格 + 最扎心的一条理由 + App 名。**不要水印压满全图**，放在底部一行就够 |
| **降低截图门槛** | 卡片本身设计得"像能发出去的图"，用户才会想截 |
| **小红书话题运营** | 盯 `#冲动消费` `#理智消费` `#存钱` `#被网友驳回` 这几个标签 |
| **每周精选"神评"** | 在 App 里做一个「本周最扎心理由」榜，给上墙用户成就感，且他们会主动转发 |

**关键指标**：分享率（分享次数 / 驳回次数）。目标 > 8%。

**为什么这条最重要**：它随用户量线性增长，且边际成本为零。买量是反向的。

---

### 渠道 2：小红书冷启动（前 1000 用户）

小红书是这个产品最精准的池子——用户画像高度重合（年轻女性、关注消费、爱看"劝退"内容）。

**具体打法**（参考 [素人矩阵打法](https://m.ebrun.com/677869.html) 的思路）：

1. **账号定位**：不是"官方号"，是"一个也在乱花钱的普通人"
   - 官方号发的内容没人看
   - 素人账号发"我又没忍住…让网友审判我"才有共鸣

2. **内容公式**：`具体商品 + 具体金额 + 网友的神回复 + 我真的没买`
   ```
   标题：¥1,360 的演唱会内场票，网友一句话劝退了我
   正文：我在一个新 App 上发起了审批，41 个人驳回。
        有个评论说："你记得上次那场吗？你全程在看手机。"
        我没买。省了 1,360。
   ```

3. **频率**：**每天 1 条，最多**。一天发多条会被判定营销号。

4. **不要做的**：
   - 不要做"产品功能讲解"（没人看）
   - 不要用"推荐一个 App"的句式（广告感太强）
   - 不要买搜索词（冷启动期 ROI 极差）

**预期**：冷启动阶段（4~6 周）目标 **1,000 真实用户**，其中 15% 成为周活。

---

### 渠道 3：Reddit / Hacker News（出海，我们的差异化机会）

**这是我们比原版多出来的一块机会**。

原版「钱包请等等」只做中文市场。我们的四语版本可以直接打英文市场，而英文市场有个天然优势：
**美国用户对"冲动消费"这个议题的讨论氛围非常成熟**（r/personalfinance、r/shoppingaddiction、r/nobuy、r/minimalism）。

**打法**（参考 [Elephas 的 Reddit playbook](https://setapp.com/how-to/launch-an-app)，6 个月做到 $3,000 MRR）：

1. 列出 15 个目标 subreddit，**优先小社区**（规则宽松、moderator 友好）
2. 帖子必须**先说问题、后说产品**：
   ```
   标题：I built a thing where strangers judge my impulse purchases before I buy
   内容：讲你为什么做这个 → 贴一张真实的审批截图 → 最后一行放 TestFlight 链接
   ```
3. **一天最多发一个 subreddit**。一天铺 15 个 = 封号
4. 每个链接带 UTM 参数，才追得到来源

**注意**：Reddit 对自我推广极其敏感。**先在社区里回答别人的问题两周，再发自己的东西。**

---

### 渠道 4：ASO（长期，慢但复利）

App Store 搜索是长期最稳的免费流量。对这个产品：

**关键词策略**（要抓"用户会搜什么"，不是"我们想叫什么"）：

| 优先级 | 关键词 | 理由 |
|---|---|---|
| 高 | 冲动消费 / impulse buying | 痛点直击 |
| 高 | 省钱 / save money | 大词，但竞争激烈 |
| 中 | 购物冷静期 / cooling off | 精准，竞争小 |
| 中 | 记账 / 不买 / no buy | 相关但不精准 |
| 低 | 消费决策 / 理性消费 | 太抽象 |

**⚠️ 绝对不要用**「省钱神器」「理财」「投资」——会触发金融类审查，还有虚假宣传风险。

**副标题**（30 字符内，权重很高）：
- 中文：`网友帮你审冲动消费`
- English: `Strangers judge your impulse buys`

## 三、增长漏斗与目标

```
曝光（小红书/Reddit/ASO）
   ↓  3% 点击
主页 / 内容页
   ↓  25% 下载
下载 → 打开
   ↓  70%
打开 → 完成第一次「发起审批」   ← 关键激活点
   ↓  40%
发起 → 收到第一条网友驳回
   ↓  30%
驳回 → 分享出去                  ← 病毒系数来源
   ↓
带来新用户（回到顶部，闭环）
```

**北极星指标不是 DAU，是「周被驳回次数」**——因为它同时代表：
用户有消费冲动（真实需求）+ 有人响应（社区活着）+ 用户看到了反馈（价值交付）。

### 分阶段目标

| 阶段 | 时间 | 目标用户 | 核心验证 |
|---|---|---|---|
| TestFlight | 第 1-2 周 | 50 人（内圈） | 能否跑通完整闭环 |
| 冷启动 | 第 3-8 周 | 1,000 人 | 次周留存 > 25% |
| 增长期 | 第 9-16 周 | 10,000 人 | 分享率 > 8%，K 因子 > 0.3 |
| 规模化 | 第 17 周+ | 50,000 人 | 付费率 > 1.5% |

**K 因子 = 每个用户平均带来的新用户数**。
如果 K > 1，产品会自增长；K = 0.3~0.5 是健康的内容型产品水平。

## 四、最容易被忽略的三件事

### 1. 第一分钟决定生死

新用户打开 App，如果看到空广场，直接卸载。

**这恰恰是我们做了「优雅降级 + 种子内容」的价值**：
没配后端，App 里也有 8 条本语言的示例申请，用户一进来就能投票。

### 2. 让用户「立刻被驳回一次」

最优的首启路径：
```
打开 App
  → 广场已有内容（种子内容）
  → 引导：「先审别人一条试试」
  → 用户投票，写理由
  → 看到别人 40 条理由
  → 被内容质量震住
  → 「那我也发一个」
```

**注意顺序**：先审别人，再发自己。
反过来（一进来就要求发内容）转化率会低一半——用户还不知道这产品是干嘛的。

### 3. 拒绝买量，至少前 6 个月

| 原因 | 说明 |
|---|---|
| 单价太高 | 这类 App 的 CPI 在国内约 ¥3~8，付费率 2% 时 CAC 远超 LTV |
| 用户质量差 | 买来的用户没真实消费冲动，不会产生有价值的内容 |
| 掩盖问题 | 买量能撑起 DAU，但撑不起留存，会让你误判产品 |

**唯一的例外**：如果你验证了 K 因子 > 0.5，可以小规模投放放大。
但在那之前，每一分投流的钱都该拿去换内容。

## 五、90 天执行清单

### 第 1-2 周：能跑起来

- [ ] **在 Mac 上编译通过**（当前最大阻塞，代码一次没编译过）
- [ ] 补隐私政策 / 用户协议网页（现在代码里指向的域名不存在）
- [ ] 补 App 图标
- [ ] 改掉占位客服邮箱
- [ ] 上 TestFlight，找 50 个人内测

### 第 3-4 周：过审上架

- [ ] Supabase 建表（含 `reports` 表）
- [ ] 验证举报/拉黑功能真的能跑
- [ ] 提审（分类选「生活」，不要选「财务」）
- [ ] 准备四语商店元数据 + 四语截图

### 第 5-8 周：冷启动

- [ ] 小红书账号建立，每天 1 条，坚持 4 周
- [ ] 做「本周最扎心理由」榜单
- [ ] 上线分享卡片功能
- [ ] 埋点：分享率、激活率、次周留存

### 第 9-12 周：判断

- [ ] 次周留存 > 25%？（低于这个数，别急着做会员，回去改产品）
- [ ] 分享率 > 8%？（低于这个数，说明内容质量不够，不是推广不够）
- [ ] K 因子 > 0.3？（达到就可以考虑小规模投放）

## 六、一句话总结

**这个产品的增长不靠推广，靠"用户被戳中后忍不住截图"。**

所以增长工作的全部重心应该是：

1. 让驳回理由足够扎心（内容质量 + 语料）
2. 让分享足够容易（一键生成图，不是截图再裁剪）
3. 让新用户第一分钟就看到好东西（种子内容 + 优雅降级）

**其他所有渠道，都是在这三件事做对之后的放大器。**
做不对就去买量，等于往漏的桶里倒水。
