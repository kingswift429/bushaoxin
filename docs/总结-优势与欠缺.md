## 二、我们的优势

### 第一层：结构性优势（抄不走）

**1. 「投票前看不到别人观点」**

普通社区：看到别人想法 → 被影响 → 趋同 → 回音室。
我们：必须先自己判断 → 才解锁别人的判断。

抄走这个规则只要一行代码，但抄不走它带来的内容质量。
**一个社区如果一开始没这条规则，后期再加会被老用户骂"你把我的内容锁了"。**

**2. 每次投票强制写理由**

决定内容密度的下限：没有理由 → 水军、刷赞、"同意"两个字。
有理由 → 每条票都是可读的真实经验。

这两条组合成**内容自净机制**：不需要运营删帖，低质量内容产生不出来。

**3. 截图 OCR 原生实现**

小程序受 WebView 限制，做 OCR 要么卡要么不准。我们用 Vision：
完全离线（不上传图片）、< 1 秒、不依赖第三方 API。

---

### 第二层：体验优势

**4. 真实生效的冷静期**

原版只有 Slogan，没做倒计时。我们做了真倒计时 + 本地通知 + 到点二选一。

**5. 多币种分开记账**（Decimal 分桶，绝不跨币种相加）

**6. 匿名登录**，不要手机号也不要微信，打开就能用

**7. 四语本地化不是机翻**：日语「ひと息」、韩语「한숨」（双关）

---

### 第三层：工程优势

**8. 优雅降级**：未配置后端时 App 完全可用（种子内容 + 模拟网友）

**9. 会员权益单一真相源**：`Entitlements.swift` 一处定义能力矩阵

**10. 举报/拉黑本地优先**：点了立刻生效，不等服务端

## 三、这次审查发现了什么

我用一个独立 agent 做了全量静态审查，**它发现了 16 个 P1 缺陷，其中 3 个会直接毁掉产品**。

### 最严重的三个（已全部修复）

**① 省钱金额统计口径完全错误**

原实现把「我驳回**别人**的申请」也算进了「为我省下」。
用户在广场上驳回 10 个人的申请，账本上就凭空多出 10 笔"省下的钱"。

这是产品最核心的情感数字，虚报等于自毁信任。
同时，冷静期结束后主动放弃购买（真正的省钱路径）反而**完全不计入**。

修复：新增 `savedForMe` 判断，只认「我自己的单 + 最终没买」。

**② 付费墙弹不出来**

`.sheet` 挂在 `ComposeView` 的子视图（`importBanner`）上，
而 `ComposeView` 本身已由父级 sheet 呈现 —— iOS 会**静默丢弃**子 sheet。
表现：用户用完 10 次免费额度，点"选图"**完全没反应**。

修复：把 sheet 移到最外层。

**③ `Info.plist` 生成方式冲突**

同时开了 `GENERATE_INFOPLIST_FILE: YES` 和 `info:` 块，两者互斥。
且 `info.path` 指向的文件根本不存在 —— XcodeGen 会直接报错。

修复：关掉自动生成，统一由 `info:` 块管理。

### 其余已修复的问题

| 问题 | 后果 |
|---|---|
| 种子数据在 `.onAppear` 灌入 | 与 @Query 赛跑，首屏可能空白或重复灌入 |
| 卡片显示"11 人已审批"但只有 2 条理由 | 用户一眼看出数据是假的 |
| 拉黑任意人会隐藏自己所有内容 | 所有本地内容 authorKey 都是 `"self"` |
| 付费墙每次打开都重新校验权益 | 沙盒环境下把刚买的会员**撤销**掉 |
| 冷静期通知 `guard` 条件写反 | 逻辑形同虚设，且已决策后仍会收到提醒 |
| 冷静期按钮用 `Date()` 而非统一时钟 | 出现"还剩 0 分"却没有按钮 |
| 欧元区输入 `9,99` 被解析成 `999` | 账本放大 100 倍 |
| OCR 取 `max()` 价格 | 永远取到原价，夸大省钱金额 |
| 日文页含"元"字被记成人民币 | 币种错误 |
| 「耳機」这类短商品名识别不出来 | `line.count < 4` 过严 |
| 会员 `ocrRemaining = Int.max` | 一旦显示会是一串天文数字 |
| `randomElement()!` 强解包 | 语料被改空时崩溃 |
| 匿名登录失败静默返回 | 后续所有写请求 401，UI 上什么都看不到 |
| 3 处硬编码中文（付费墙、理由标签） | 海外用户看到中文 |
| 隐私清单多声明 FileTimestamp | 审核时会被追问 |
| 广场每帧做全表查询（3 次） | 内容变多会卡 |

### 关于「不用 Mac 也能编译」的发现

原本以为必须买 Mac 才能往下走，实测下来**不成立**：

**GitHub Actions 提供免费 macOS 机器**，可以真跑 `xcodebuild`。
仓库里已配好 `.github/workflows/build-ios.yml`，push 代码 → 点运行 → 拿编译错误。

免费额度：公共仓库不限，私有仓库约 200 分钟 macOS/月 ≈ 编译 20 次。

这条路的边界要说清楚：
- ✅ 能验证代码能不能编译、有哪些 error/warning、产物是否完整
- ❌ 看不到界面长什么样、点下去有没有反应

**界面仍然需要接触一次 Mac**（借半天或云 Mac 一两小时，成本约等于零）。
