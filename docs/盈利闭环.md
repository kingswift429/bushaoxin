# 不烧心 · 盈利闭环方案

> 原则：**先验证留存，再谈变现**。原产品作者明确说"不急"，这个判断是对的。
> 过早变现会让社区调性崩塌，而这类产品的唯一资产就是社区调性。

---

## 一、先说结论

| 阶段 | 触发条件 | 主变现方式 | 月收入量级 |
|---|---|---|---|
| P0 免费期 | 0 ~ 1 万 DAU | 无（专心做留存与内容） | 0 |
| P1 轻变现 | 1 万 DAU，次月留存 > 25% | 会员订阅 | ¥2k ~ 1.5万 |
| P2 规模化 | 5 万 DAU | 会员 + 平替返利 | ¥3万 ~ 15万 |
| P3 生态 | 20 万 DAU | 品牌合作 + 年度报告 | ¥10万+ |

**关键判断**：这类产品 DAU 天花板不高（不是刚需高频工具），
但**ARPU 可以很高**——因为用户正在花钱的决策点上，这是电商最贵的位置。

## 三、四条变现阶段详解

### P1 · 会员订阅（主收入，最先做）

**为什么会员而不是广告**：
原作者说"看不上接开屏广告，有点 low"——这个判断商业上也是对的。
这个产品的情感价值是"帮我不乱花钱"，而广告的逻辑是"让你多花钱"。
**开屏广告会直接破坏产品叙事**，是自杀式变现。

#### 免费 vs 会员

| 能力 | 免费 | 会员 ¥18/月 或 ¥128/年 |
|---|---|---|
| 广场审批 | ✅ 无限 | ✅ |
| 截图自动填单 | 每月 10 次 | ✅ 无限 |
| 冷静期 | 固定 24h | ✅ 2h/12h/24h/3天 可选 |
| 审批群 | 1 个，10 人 | ✅ 无限群，500 人 |
| 省钱账本 | 累计金额 | ✅ 分类分布 + 月度报告 + 年度总结 |
| 多币种记账 | ✅ | ✅ |
| 数据导出 | ❌ | ✅ CSV / 图片分享 |
| 主题皮肤 | 1 套 | ✅ 全部 |
| 去水印分享图 | ❌ | ✅ |

**定价依据**：
- ¥18/月 的心理锚点是"省下的一顿饭钱"，低于用户第一次被驳回的金额（中位数 ¥50~120）
- 年费 ¥128 = 月费的 59 折，符合国内订阅习惯
- **不要做 ¥6/月的低价**：低价吸引来的是价格敏感用户，会拉低社区质量

#### 收入测算（保守）

```
付费率 2%（工具类 App 的常见区间 1%~5%）
ARPPU ¥15/月（按月费 8 折混合年费摊薄）

1 万 DAU  → 付费用户 200 → ¥3,000/月
5 万 DAU  → 付费用户 1,000 → ¥15,000/月
```

#### 苹果抽成（2026 最新，已核实）

| 情形 | 佣金率 |
|---|---|
| 中国大陆标准 | **25%**（原 30%，2026/3/15 起） |
| 小企业计划（年收入 < $100 万） | **12%**（原 15%） |
| 首年后的自动续费订阅 | **12%** |

> 来源：[证券时报](https://stcn.com/article/detail/3675130.html)、[IT之家](https://m.ithome.com/html/928601.htm)

**务必加入 Small Business Program**，12% 对 25% 差一倍。
按 ¥15,000/月、12% 抽成计算，实收 ¥13,200。

### P2 · 平替返利（第二收入，与产品逻辑天然契合）

#### 为什么这是最好的第二曲线

产品里本来就有「替代方案」字段。用户被驳回后，最自然的下一步是：
**"那有没有更便宜的？"**

在这个位置推荐平替商品，用户不会觉得被打扰——他本来就要找。

#### 链路设计

```
用户被驳回
   ↓
卡片下方出现：「网友提到了 3 个平替」
   ↓
点开 → 平替详情页（比价 + 跳转）
   ↓
跳转淘宝/京东/拼多多（带推广位 ID）
   ↓
成交 → 佣金 1%~30%（类目差异大，数码低、服饰高）
```

#### 合规红线（必须做，否则有法律风险）

1. **必须显著标注**「本页含推广链接，成交后我们可能获得佣金」；
2. 不能只推有佣金的商品而隐藏更好更便宜的选项——这是《广告法》隐性广告问题；
3. **不要做"虚假平替"**：为了佣金推荐更贵的商品，一旦被发现社区信任瞬间崩塌。

#### 收入测算

```
5 万 DAU，被驳回率约 60%，日产生 3 万次驳回
点击平替率 8% → 2,400 次点击/日
转化率 3% → 72 单/日
客单价 ¥80，平均佣金率 8% → ¥6.4/单
日收入 ¥460 → 月收入约 ¥1.4 万
```

⚠️ 这一块**不确定性最大**，且需要接淘宝联盟/京东联盟资质（个人开发者可能受限）。
建议放到 P2，等有量了再谈。

### P3 · 品牌合作与年度报告

#### 年度报告（最好的增长引擎）

类似 Spotify Wrapped：

> 「2026 年，网友帮你省下 ¥12,847
> 你被驳回最多的品类是：数码
> 最常拦住你的人是：一位匿名的上海网友
> 你的年度关键词：不烧心」

**这是免费的用户增长，不是变现**。但报告页可以带品牌赞助位，
且报告本身极容易被分享到小红书、朋友圈——一次刷屏抵十万投放。

#### 品牌合作

不做硬广，做**联名审批场景**：
- 某茶饮品牌赞助一个「今天我们替你审批奶茶」活动周
- 品牌方提供真实优惠券作为"平替"出现在卡片里

底线：**任何商业内容必须可识别、可关闭**。

## 四、明确不做的（重要）

| 方案 | 为什么不做 |
|---|---|
| 开屏广告 / 信息流广告 | 破坏"帮你省钱"叙事，用户会觉得被背叛 |
| 卖用户数据 | 消费记录是最敏感的隐私，一旦出事就是灭顶 |
| 导流到借贷/分期 | 产品目标是"不让你买"，借贷是"给你钱买"，逻辑相反且涉金融资质 |
| 抽奖/养成类游戏化付费 | 会把这批理性消费用户直接赶走 |
| 早期的"付费解锁审批人数" | 把核心体验变成付费墙，留存必崩 |

## 五、转化漏斗设计（怎么让用户付费）

### 触发点（全部植入自然场景，不做弹窗强推）

| 场景 | 触发 | 提示 |
|---|---|---|
| 第 11 次截图识别 | 免费额度用完 | 「本月自动填单次数已用完，会员无限」 |
| 想选 2 小时冷静期 | 点击被锁的选项 | 「会员可选 2 小时 / 3 天」 |
| 想开第二个审批群 | 点新建 | 「免费版 1 个群，会员无限」 |
| 月度结束时 | 进「我的」 | 「本月省下 ¥1,280，看分类明细 →」 |
| 省下累计过千 | 达到里程碑 | 「你已省下 ¥1,000，会员可看完整报告」 |

**原则：只在用户已经想要某个东西时提示，不在他不想的时候打扰。**

### 定价页设计

- 默认选中**年费**（¥128），月费作为对照（¥18）
- 强调"7 天免费试用"，降低决策门槛
- 文案用产品语言：**「省下一顿饭钱，换个不烧心的整月」**

## 六、单位经济模型（UE）

```
ARPU（每付费用户年净收入）
  = ¥128 × 88%（扣 12% 苹果佣金）
  = ¥113

获客成本 CAC
  = 内容营销（小红书/短视频）为主，主要是时间成本
  = 假设投流 ¥0.5/安装，付费率 2%
  = ¥25 / 付费用户

LTV = ARPU × 平均续订年数
    = ¥113 × 1.6 年（工具类年费续订率约 45%）
    = ¥181

LTV / CAC = 7.2  ✅ 健康（>3 即可行）
```

这是**纯自然流量**的算法。一旦开始投流，CAC 会显著上升，需重新测算。
